### 2. AlgoVis — Interactive Algorithm Visualization

An interactive algorithm laboratory featuring a custom programming language interpreter and real-time execution visualization.

- Custom lexer, parser, AST and interpreter
- Step-by-step code execution and debugging
- Runtime environment and call-frame inspection
- Interactive data structure visualization
- Canvas and PixiJS rendering engines
- Optional desktop application using Tauri

**Tech Stack:** TypeScript, React, Vite, Monaco Editor, PixiJS, Tailwind CSS, Tauri 2.

🔗 [View Repository](https://github.com/prashant-180206/AlgoVis)

### 3. TrustLance — Decentralized Freelancing Platform

A blockchain-powered freelancing platform designed around milestone-based smart contract escrow.

- Smart-contract-based fund management
- Milestone submission and approval workflows
- Automated review and dispute deadlines
- Wallet connectivity and blockchain interaction
- Supabase-backed application infrastructure

**Tech Stack:** Solidity, Hardhat 3, OpenZeppelin, React, TypeScript, Vite, Supabase, Wagmi, Viem.

🔗 [View Repository](https://github.com/prashant-180206/trustlance)
